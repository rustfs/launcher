## Summary

Comprehensive code quality and security improvements across the launcher codebase.

### Security
- **Credentials via env vars**: Access/secret keys now passed as environment variables instead of CLI args (visible in `ps aux`)
- **CSP enabled**: Content Security Policy set to restrictive self-origin (was null)
- **Capabilities**: Added missing Tauri permissions for shell, store, window-state plugins
- **Path validation**: data_path now rejects path traversal and flag injection

### Reliability
- **Poisoned mutex recovery**: All lock().unwrap() replaced with acquire() helper that recovers from poisoned mutexes
- **Close handler safety**: window.hide().unwrap() replaced with let _ = to prevent panic
- **Monitor thread shutdown**: Added AtomicBool signal so the monitor thread exits gracefully
- **Interval stacking fix**: Health check effect now clears the previous interval before creating a new one
- **Listener dedup**: config_form file-drop listeners registered only once via Cell guard

### Performance
- **Parallel IPC**: check_tcp_connection and is_rustfs_process_running now run concurrently via futures::join!
- **Leaner tokio**: Features trimmed from full to rt-multi-thread + sync
- **Removed unused deps**: leptos_router removed

### Code Quality
- **Consistent logging**: println! replaced with log::info!/log::warn!
- **Toast safety**: ID collision fixed (atomic counter), window unwrap guarded
- **Secret redaction**: Added env var format patterns
- **Cleanup**: Removed GEMINI.md and AGENTS.md from repo

### Verification
- cargo check (backend) - pass
- cargo check --target wasm32-unknown-unknown (frontend) - pass
- cargo clippy --workspace --all-targets - 0 warnings
